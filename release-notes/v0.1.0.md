# firstmate-lanes v0.1.0

The first public release provides a fleet board for Ask, List, Fleet and Lane, with matching web, phone and terminal views.

- Read fleet data across configured homes, and send confirmed answer batches to Firstmate.
- Review and confirm supported answers through the installed Firstmate intake command.
- Serve the embedded web board and its fonts from the same executable.
- Explore synthetic lane data with procedural ship views.
