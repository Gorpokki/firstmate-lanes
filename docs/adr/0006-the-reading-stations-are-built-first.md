# The reading stations are built first

The List, Fleet and Lane stations can read the status files that crews write today. The Ask station cannot: it needs each ask in the fixed form, a lane record from each crew, and a path for the user's answers into Firstmate, and all three need a change to how Firstmate briefs its crews. So the build starts with the List, Fleet and Lane stations for web and phone, on today's status files. The change to Firstmate comes second, and the Ask station with its send comes third. Until the Ask station is built, asks reach the user through the chat, as they do now. The terminal version comes after the web and phone version.

## Considered options

- The Ask station first: the decision screen is the part the user needs most, but the user can use nothing until the change to Firstmate is done.
- One build with all of it: one release, and the longest wait before any part is usable.
