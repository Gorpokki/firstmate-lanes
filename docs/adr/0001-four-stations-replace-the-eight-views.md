# Four stations replace the eight views

The first dashboard had eight views (All, Alert, Health, Captain, Lanes, Crew, Log, Holo), and one screen often carried five or six things. Forty rounds of design review showed that screens like that fail on reading load, while a design with one thing on each screen passes. So the dashboard has four stations only (Ask, List, Fleet, Lane), each one key from the others, and the eight views are removed and not kept beside them.

## Considered options

- Keep the eight views one key away: rejected, because two dashboards must then stay in step.
